# Requirements Archive: Linktree v1.0

**Archived:** 2026-08-15
**Milestone:** v1.0 — Production-Ready, Secure Multi-Tenant Linktree Platform
**Core Value:** A stranger opens `/username` and sees a page that loads fast, looks good, and whose links work — every time, without the owner having to check on it.

## Shipped v1 Requirements

### Security (10/10 Complete)
- [x] **SEC-11**: An email that is not on the allowlist cannot sign in, and sees a clear invite-only message rather than a generic error
- [x] **SEC-12**: All pre-existing data (Pages, Users, Events, NextAuth adapter collections, and every S3 object) wiped once before gates went live
- [x] **SEC-01**: `/api/upload` rejects requests without a valid session
- [x] **SEC-02**: Uploads are rejected above a 5MB size cap (server-enforced)
- [x] **SEC-03**: Uploads are rejected unless the content type is an allowlisted image format verified by magic-byte inspection
- [x] **SEC-04**: A single account cannot exceed a per-user 25MB upload quota
- [x] **SEC-05**: Write endpoints (upload, page save, username claim) are rate limited per user
- [x] **SEC-06**: Reserved usernames (`api`, `account`, `login`, `about`, admin-ish words) cannot be claimed
- [x] **SEC-07**: Usernames are validated for charset and length before becoming a public URL
- [x] **SEC-08**: `/api/click` handles malformed input without throwing a 500

### Correctness (9/9 Complete)
- [x] **FIX-01**: `SavePageLinks` returns true on database persistence
- [x] **FIX-02**: A taken username does not redirect to the success page and preserves form state
- [x] **FIX-03**: An unknown `/username` renders a modern 404 page instead of crashing with a 500
- [x] **FIX-04**: No view Event is written for a profile that does not exist
- [x] **FIX-05**: Missing avatar or background image renders safe fallbacks
- [x] **FIX-06**: `params` is awaited per Next.js 15 async dynamic route API
- [x] **FIX-07**: Analytics link rows use stable keys instead of dynamic UUIDs per render
- [x] **FIX-08**: Social button icons render static brand colors with neutral fallback
- [x] **FIX-09**: Unified MongoDB connection pool through `lib/connectToDB.js`

### Admin, Uploads & Governance (4/4 Complete)
- [x] **ADMIN-01**: Admin Control Center lists allowlisted emails, pending creator invite requests, and user bug reports/feedback
- [x] **ADMIN-02**: Non-admin users are strictly forbidden from viewing or executing admin actions
- [x] **UPLOAD-01**: Dashboard lists creator uploads with thumbnail, size, and total against the 25MB quota
- [x] **UPLOAD-02**: Deleting an upload removes S3 object and DB record, and warns if image is in active use

### QR Code Sharing (2/2 Complete)
- [x] **QR-01**: Dashboard displays a QR code that resolves to the owner's public page
- [x] **QR-02**: The QR code can be downloaded as a 1024px print-ready high-resolution PNG or SVG

### Themes & Gradients (3/3 Complete)
- [x] **THEME-01**: 8 curated preset themes offered in page settings
- [x] **THEME-02**: 1-click theme presets apply with live phone preview before saving
- [x] **THEME-03**: Custom 2-color gradient engine, custom solid colors, and background images work seamlessly

### Link Lifecycle Management (4/4 Complete)
- [x] **LINK-01**: Links can be toggled active/inactive without deletion
- [x] **LINK-02**: Inactive links are hidden from the public page and preserved in the dashboard
- [x] **LINK-03**: Links support optional UTC publish start and end schedules
- [x] **LINK-04**: Public profile evaluates schedules deterministically against captured render timestamp

### Actionable Analytics (4/4 Complete)
- [x] **ANA-01**: Click & view events capture normalized referrer and device platform
- [x] **ANA-02**: Analytics dashboard provides 7-day and 30-day timeline views
- [x] **ANA-03**: Links are ranked by click count and CTR over the selected window
- [x] **ANA-04**: Empty states render cleanly when no event data exists

### Presentation & Docs (3/3 Complete)
- [x] **DOC-01**: README covers platform architecture, live Vercel URL, and local setup
- [x] **DOC-02**: Authentic screenshots included for public profile and creator dashboard
- [x] **DOC-03**: `.env.example` documents every environment variable required
