## Overview

The Linktree platform is transformed into a high-performance, secure, multi-tenant link-in-bio application. This milestone closed vulnerable write endpoints, established invite-only allowlist governance, cleared 9 confirmed defects, implemented owner link scheduling, 8 curated design themes with live phone header preview, 1024px print QR code export, and zero-dependency SVG analytics.

## Milestone Summary

**Key Decisions:**
- **Invite-Only Allowlist (`AllowedUser`):** Gated registration to prevent abuse while keeping all public profile pages open to everyone.
- **One-Time Data Wipe (`scripts/wipe.js`):** Eliminated legacy unvalidated records for a clean slate across MongoDB and S3.
- **Unified MongoDB Pooling (`lib/connectToDB.js`):** Eliminated scattered `mongoose.connect()` calls to prevent connection leaks on serverless execution.
- **Deterministic Link Evaluation (`lib/linkLifecycle.js`):** Captured single render timestamp on public page to evaluate scheduled and expired links consistently.
- **Zero-Dependency SVG Analytics (`components/Graf.js`):** Replaced heavy external chart libraries with pure responsive SVG vector paths.

**Technical Debt Incurred:**
- `verify-phase1.js` post-wipe assertion verifies empty DB/S3 state immediately after wipe; future tests run against active development database with seed records.
