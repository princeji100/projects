# Phase 1.5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `gray-100` | Background, surfaces (`bg-gray-100`) |
| Secondary (30%) | `white` | Cards (`SectionBox`), sidebar, nav (`bg-white`) |
| Accent (10%) | `blue-600` | Primary buttons, active nav state, progress bar |
| Destructive | `red-500` | Delete upload, Remove user actions |

Accent reserved for: Primary submit buttons, active sidebar tab indicator, quota progress bar fill.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Add User", "Delete Upload" |
| Empty state heading | "No users allowed yet", "No uploads yet" |
| Empty state body | "Add an email below to grant access.", "Upload images from your page settings to see them here." |
| Error state | "Action failed. Please try again or check your permissions." |
| Destructive confirmation | **Remove User**: "Are you sure you want to revoke access? Session will be terminated immediately."<br>**Delete Upload**: "Are you sure? This image is currently in use as: {list}. It will be removed from these places." |
