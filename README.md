## Running locally

Most builds are plain HTML/CSS/JS — open `index.html` and you're done.

The ones with a `package.json` (`linktree`, `TodoApp`, `ReactNative/MovieApp`) need:

```bash
cd <project-folder>
npm install
npm run dev
```
